Optional homepage background video: `assets/video/worship-hero.mp4`. **MP4**, not MPV. Export muted/loop-friendly footage without embedded text, ideally less than ~10 MB; use authentic footage with appropriate permission. If video is missing the hero still displays with the provided image or the fallback graphic.

Suggested specifications: hero image 1920×1080 PNG; photos 1200×900 PNG; portrait photos 1000×1200 PNG; sermon thumbnails 1280×720 PNG. Compress large files before upload to keep pages fast.

Existing church logo: save as `assets/images/church-logo.png` for a future header update. The current header uses a text-based identity while awaiting a high-resolution logo.

DO NOT upload personal data, private membership spreadsheets or confidential prayer requests to the public GitHub repository.
