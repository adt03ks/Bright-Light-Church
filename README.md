# Bright Light Church — GitHub Pages redesign

A responsive, multi-page static site using HTML/CSS/JavaScript, designed around the existing Wix site screenshots.

## Files/pages

- `index.html` — homepage
- `about.html` — history, mission, values
- `leadership.html` — pastoral and ministry leadership
- `ministries.html` — ministry opportunities
- `watch.html` — Bright Light TV / sermon placeholders
- `events.html` — upcoming events
- `visit.html` — first-time visitor information
- `giving.html` — giving methods
- `services.html` — weddings, baptisms, funerals, baby dedications
- `contact.html` — questions and prayer (FORM NOT CONNECTED)
- `styles.css`, `script.js` — shared design and interactions
- `ASSET_CHECKLIST.md` — exact asset filenames
- `LAUNCH_CHECKLIST.md` — required approvals and setup

## Upload to GitHub

1. Create a new public GitHub repository (e.g. `bright-light-church`).
2. Upload the **contents of this folder** to the repository root, including the `assets` folder.
3. In Settings → Pages, choose Deploy from branch → `main` → `/ (root)`.
4. Test the temporary github.io URL before changing DNS or canceling Wix.
5. Connect your custom domain under Settings → Pages. Verify DNS using GitHub's official docs, and keep email-related DNS records intact.
